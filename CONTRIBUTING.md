# Contribution policy

This is an owner-maintained project. The repository does not accept pull
requests, issues, or discussions. This includes bug reports, feature requests,
and documentation changes. No support, response, review, or release schedule
is promised. There is no alternative contact route for submissions.

The [MIT license](LICENSE) permits you to use, copy, modify, and distribute
the code under its terms. You can fork the project and maintain your own
changes. A fork does not create an obligation for the owner to accept changes
or provide support.

The owner may intentionally change this policy later. An enabled feature does
not promise a response or acceptance. Anyone invited to contribute remains free
to decline an invitation or stop contributing.

The [maintainer guide](docs/MAINTAINING.md) describes local verification,
release preparation, and the controls for changing this policy.
